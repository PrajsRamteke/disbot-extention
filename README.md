## 🚀 How to Install

1.  **Download** the files using the links above.
2.  If you downloaded the `.zip`, **unzip** it to a folder on your computer.
3.  Open your browser (Chrome/Edge/Brave) and go to: `chrome://extensions/`
4.  Enable **"Developer mode"** in the top right corner.
5.  Click on **"Load unpacked"**.
6.  Select the folder where you unzipped the extension (the folder containing `manifest.json`).

---

## ✨ Features

- **Pick colors** from any element on the page.
- **Copy codes** in various formats (Hex, RGB, HSL).
- **History** of recently picked colors.
- **Clean UI** and fast performance.
